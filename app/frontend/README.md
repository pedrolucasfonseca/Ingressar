# Ingressar (Frontend)

React + TypeScript + Vite. Ver o [README da raiz do projeto](../../README.md) para visão geral, arquitetura e como rodar tudo junto com a API.

```bash
npm install
cp .env.example .env   # preencha VITE_STRIPE_PUBLISHABLE_KEY
npm run dev             # http://localhost:5173, requer a API em http://localhost:3001
```
